# 我的健康记录

一个手机优先的单页静态网站，用来记录每日饮水与运动。

- **无后端、无依赖、无需登录**：整站只有一个 `index.html`
- **数据保存在访问者自己的浏览器**（localStorage），刷新不丢；换设备/换浏览器不跟随
- **每位访问者独立**：首次打开显示默认昵称「健康记录员」与空记录，互不影响

## 功能

| 模块 | 说明 |
|---|---|
| 顶部 | 🌱 固定头像，昵称可随时修改 |
| 饮水 | 点一次 +250 ml，固定目标 2000 ml，实时显示合计 / 目标圆环 / 完成百分比 / 还差多少 |
| 运动 | 跑步 / 散步 / 骑行 / 拉伸 / 瑜伽 五个项目，颜色随机分配后固定不变；跑步散步骑行记公里与分钟，拉伸瑜伽只记分钟；跑步显示单次与今日平均配速 |
| 撤销 | 每条记录右侧 `×`，撤销后合计与进度同步回退 |
| 今日记录卡 | 一键生成含头像、昵称、日期、饮水完成情况与运动数据的图片，可保存 PNG，手机也能长按保存 |

## 部署

GitHub Pages，源文件为仓库根目录的 `index.html`。

本地预览：直接用浏览器打开 `index.html` 即可，无需构建、无需联网。
